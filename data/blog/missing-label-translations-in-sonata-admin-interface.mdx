Somehow, no translations seemed to be loaded in the sonata admin interface. After a while I found out that our locale was defaulted to 'nl' while there are no available standard translations for Dutch. Adding the fallback to the config file solved the problem, now showing English button labels.

```yaml
# /app/config/config.yml

framework:
translator:
fallback: en
```
